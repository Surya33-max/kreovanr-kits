# Kreovant Kits

Curated and customized digital product packages developed for Kreovant.

## Packages

- **Launchpad Web Kit v1.0.0** — original responsive landing-page starter.
- **Thu4der WhipRush DaVinci Resolve/Fusion v1.0.0** — editable whip-pan/zoom macro with pan direction and zoom controls. Package archive is stored in the Kreovant resource library; the binary ZIP still needs attaching to this GitHub repository through a supported binary/release upload path.

## Package validation

WhipRush's .setting macro is bundled with OS-specific installation instructions. It has not been rendered in a live DaVinci Resolve installation in this environment; test the macro in your Resolve version before client delivery.
