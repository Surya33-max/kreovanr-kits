## Binary archive status

The ZIP archives above exist in the user's ChatGPT Library, but their binary bytes have **not** been committed to this repository yet. The connected GitHub tools in this workflow can create/update text files but do not expose a release-asset upload operation. A README entry is not the archive, despite the internet's many attempts to pretend otherwise. Use GitHub's web interface or a local authenticated Git client to upload the actual ZIPs under `releases/` or as release assets.
